# Ilustraciones Personalizables por Método

Guarda una imagen `.png`, `.jpg` (`.jpeg`) o `.svg` en esta carpeta usando la clave exacta de la tarjeta para reemplazar su ilustración borrador sin modificar el código fuente.

Si no existe archivo personalizado, Arandú renderiza automáticamente el diagrama SVG borrador correspondiente.

## Fichas de Métodos (`views/view_*.py`)
- **Fundamentos:** `taylor`, `aritmetica_maquina`, `cancelacion`, `horner`
- **Raíces:** `biseccion`, `regula_falsi`, `newton_raphson`, `punto_fijo`
- **Sistemas:** `gauss`, `gauss_jordan`, `lu`, `gauss_seidel`, `potencias`, `faddeev`
- **Interpolación:** `interp_lineal`, `cuadratica_inversa`, `lagrange`, `newton_gregory`
- **Integración:** `diferenciacion`, `trapecios`, `simpson_13`, `simpson_38`
- **EDO:** `euler_heun`, `runge_kutta`, `milne`

## Tarjetas del Catálogo Principal (`views/inicio.py`)
- `fundamentos`, `raices`, `sistemas`, `interpolacion`, `integracion`, `edo`, `arena_versus`, `laboratorios`, `feedback`
